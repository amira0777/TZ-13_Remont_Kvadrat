# Проверочные снимки

Подпапки для доказательств, которые нужно сохранять только после реального подключения соответствующих сервисов:

- \`ga4/\` — GA4 DebugView с раскрытыми параметрами всех событий.
- \`utm/\` — переходы по ссылкам из публикаций и отчёт Traffic acquisition.
- \`instagram/\` — обе ветви ManyChat от комментария до Direct-кнопки.
- \`reports/\` — стандартные отчёты GA4.
- \`explore/\` — исследования GA4.
- \`datalens/\` — три вкладки дашборда.
- \`lighthouse/\` — сохранённый Lighthouse отчёт главной страницы.

В \`lighthouse/\` находится фактический аудит локальной версии сайта. Остальные снимки не добавлены, поскольку аккаунты не подключены и проверки там не выполнялись.
