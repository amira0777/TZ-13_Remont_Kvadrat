# Настройка GA4 для учебного сайта

Measurement ID `G-Q7HG6F0JEZ` подключён во всех HTML-страницах. Для завершения настройки откройте в GA4 **Администратор → Отображение данных**.

Статус на 9 ноября 2026 года: поток сайта создан, семь специальных параметров ниже уже добавлены. Ключевые события и DebugView не настраивались по просьбе заказчика.

## Ключевые события

В разделе **События** отметьте как ключевые:

- `generate_lead` — только после успешного ответа Apps Script;
- `contact_click` — переход по телефону или e-mail;
- `messenger_click` — переход в мессенджер.

Если этих имён ещё нет в списке событий, сначала вызовите действия на сайте и вернитесь к настройке после появления событий.

## Специальные параметры

В разделе **Специальные определения** проверьте параметры с областью **Событие** и точными именами:

| Параметр | События |
|---|---|
| `button_name` | `cta_click` |
| `page_section` | `cta_click`, `social_click` |
| `repair_type` | `repair_type_select`, `repair_calc` |
| `area_m2` | `repair_calc` |
| `object_type` | `portfolio_filter` |
| `lead_repair_type` | `generate_lead` |
| `messenger` | `messenger_click` |

## DebugView

В **Администратор → Отображение данных → DebugView** проверьте `page_view`, калькулятор, фильтр портфолио, этапы, скачивание PDF и успешную тестовую заявку. Используйте только синтетические контактные данные. Не передавайте в GA4 имена, телефоны, e-mail или `request_id`.
