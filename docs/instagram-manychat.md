# ManyChat для Instagram

## Текущий статус

По сообщению пользователя от 9 ноября 2026 года Reel опубликован, а автоматизация ManyChat с ключевым словом `ПРИЁМКА` отправляет сообщение и рабочую ссылку. Пользователь подтвердил успешную проверку.

Вторая ветка `САНУЗЕЛ` не настраивалась; она не нужна, если достаточно одной темы.

## Основная ветка: ПРИЁМКА

- Триггер: комментарий под выбранным Reel содержит ключ `ПРИЁМКА`.
- Ответ в комментариях: `Отправили чек-лист в директ 📩`.
- Direct: `Здравствуйте! Это учебная демонстрация «Квадрат». Чек-лист «Как принять ремонт: 25 пунктов» — по кнопке ниже.`
- Кнопка: `Открыть чек-лист` → открыть сайт.
- URL: `https://remont-kvadrat.vercel.app/u/u-02`.

## Проверка

Пользователь подтвердил, что сообщение и переход по ссылке работают. При дальнейших проверках учитывать, что Instagram может запускать триггер только для первого подходящего комментария пользователя под публикацией. Для тестовой заявки использовать только синтетические контактные данные.
