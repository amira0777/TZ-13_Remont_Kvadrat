# ManyChat для Instagram

## Текущий статус

По сообщению пользователя от 9 ноября 2026 года Reel опубликован и выбран в триггере комментариев ManyChat. Черновик основной автоматизации настраивался с ключевым словом `ПРИЁМКА`, одним ответом в комментариях и Direct-сообщением с кнопкой на UTM-ссылку U-02. Статус `Live` и доставка сообщения не подтверждены; автоматизацию нельзя считать проверенной.

Для включения откройте черновик, нажмите Preview, проверьте выбранный Reel, ключ `ПРИЁМКА`, текст и кнопку `Открыть чек-лист` с URL `https://remont-kvadrat.vercel.app/u/u-02`. Если всё верно, нажмите Set Live. Второй поток `САНУЗЕЛ` не нужен, если достаточно одной темы.

## Основная ветка: ПРИЁМКА

- Триггер: комментарий под выбранным Reel содержит ключ `ПРИЁМКА`.
- Ответ в комментариях: `Отправили чек-лист в директ 📩`.
- Direct: `Здравствуйте! Это учебная демонстрация «Квадрат». Чек-лист «Как принять ремонт: 25 пунктов» — по кнопке ниже.`
- Кнопка: `Открыть чек-лист` → открыть сайт.
- URL: `https://remont-kvadrat.vercel.app/u/u-02`.

## Проверка после включения

1. Со второго Instagram-аккаунта оставить новый комментарий `ПРИЁМКА` под выбранным Reel. Триггер может срабатывать только на первый подходящий комментарий пользователя под публикацией.
2. Убедиться, что появился публичный ответ и пришло Direct-сообщение с кнопкой.
3. Открыть кнопку и проверить переход на страницу чек-листа с UTM-метками.
4. Для тестовой заявки использовать только синтетические контактные данные.
